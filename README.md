# Сравнительная таблица цен на акустические кабины

Сайт: `index.html`, данные: `prices.json`. Публикуется через GitHub Pages.

## Как обновляются цены

1. Каждый день в 06:07 по Москве запускается задание «Обновление цен конкурентов» (вкладка **Actions**).
2. Скрипт `update.mjs` открывает страницы моделей из `prices.json` и находит на каждой цену.
3. Если цена изменилась, она обновляется, старая остаётся в истории модели (поле `hist`).
4. Если страница не открылась или модель пропала, цена остаётся прежней, а рядом с датой проверки встаёт оранжевая точка.
5. Скачок цены больше чем вдвое автоматически не применяется: модель помечается «на проверку».
6. После проверки сайт публикуется заново.

Запустить вручную: **Actions → Обновление цен конкурентов → Run workflow**.

## Как добавить модель или конкурента

Каждая модель в `prices.json` — запись в `items`:

```json
{
  "id": "str-200", "c": "str", "model": "Название модели", "cls": "1",
  "price": 300000, "url": "https://страница-с-ценой",
  "ext": { "mode": "auto" }
}
```

- `ext.mode: "auto"` — страница одного товара: цена берётся из разметки товара или первая цена после заголовка.
- `ext.mode: "near"` + `anchor` — страница со списком: цена ищется сразу после текста `anchor`, `nth` — какая по счёту цена после него.
- `cls` — класс: `1`, `1+`, `2`, `4`, `6`, `8`, `open`, `atm`.
- У конкурента флаг `vat_excl: true` значит, что на его сайте цены без НДС и на сайте таблицы к ним прибавляется 22%.

Проверить разметку без записи: `node update.mjs --check` или `node update.mjs --check --only=str`.
